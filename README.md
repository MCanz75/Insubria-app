# Insubria App v10

Versione pronta per la pubblicazione su GitHub Pages.

## Cosa cambia nella v10
- Icona iPhone/Safari resa compatibile con file standard nella **root** del sito.
- Aggiunti `apple-touch-icon.png` e `apple-touch-icon-180x180.png`.
- Aggiunti `icon-192.png`, `icon-512.png` e `favicon.png` nella root.
- Manifest PWA aggiornato alla v10.
- Service worker aggiornato a `insubria-v10` per forzare il rinnovo della cache.
- Logo del club servito come `club-logo.png`.
- Le funzionalità dell'app e lo schema Supabase non vengono modificati da questa versione.

## Pubblicazione su GitHub
1. Sostituire i file dell'app del repository con **tutti i file contenuti in questa cartella**.
2. Non cancellare o modificare il progetto Supabase.
3. Assicurarsi che GitHub Pages pubblichi la stessa cartella/branch usata finora.
4. Attendere la pubblicazione di GitHub Pages.
5. Aprire l'URL dell'app in Safari e verificare prima il logo nella schermata di login.
6. Eliminare la vecchia icona dalla Home dell'iPhone e aggiungere nuovamente il sito da Safari con **Condividi → Aggiungi alla schermata Home → Apri come app web**.

## Importante
Non è necessario cancellare le immagini precedenti da GitHub prima del caricamento. I file della v10 includono già le icone standard e possono convivere con i vecchi file.
